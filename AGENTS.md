# Repository notes

## ui-sdk

ui-sdk is installed in the `apps/calc-paye-kenya` and `apps/calendar` Solid apps.
Before using ui-sdk, follow the ui-sdk skill if it's installed, and read
`node_modules/@ui-sdk/solid/docs/llms.txt`. To build a new component, also search
`node_modules/@ui-sdk/solid/docs/core.md` by heading, and read `rendering.md` next
to it.

Paths above are relative to the app you are working in (`apps/calc-paye-kenya/`
or `apps/calendar/`), where the packages are installed.
